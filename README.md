# 🧠 TheraFusion – Speech-Language Therapy Software

TheraFusion is an speech and language therapy assistant designed to support individuals with communication disorders. It provides interactive exercises, progress tracking, and intelligent feedback — blending technology with personalized therapy.

## 🌟 Features
  
💬 **Language Exercises** – Customizable word and sentence practice.  
📊 **Progress Tracking** – Visual reports showing user improvement over time.  
🧩 **Therapist Dashboard** – Manage multiple clients, sessions, and performance analytics.  
🧠 **AI Insights** – AI chat bot for asking queries.  
🎨 **User-Friendly Interface** – Simple, engaging design for children and adults.
